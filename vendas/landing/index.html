What you get

  • subflow run - full pipeline (download, transcribe, translate, clean, QC)
  • subflow qc --profile netflix - automatic QC report
  • subflow langcheck - re-decodes each cue, flags ASR hallucinations
  • subflow clean --merge --extend - fixes Whisper cuts and reading-speed issues
  • SKILL.md - Claude Code skill for agent-assisted translation
  • stdlib-only Python 3.10+ - no exotic deps
