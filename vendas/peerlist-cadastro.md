## Descrição (longa)

```
SubFlow turns any video (URL or file) into professional translated subtitles, fully offline.

Pipeline: download → transcribe with Whisper (int8_float16 fits 4GB GPUs) → build glossary → translate in batches → build SRT → clean → Netflix-style QC (max 42 chars/line, CPS 17-20, no overlaps) → langcheck (catches ASR hallucination, e.g. Whisper inventing French over Hassaniya Arabic lyrics).

A 104-minute documentary that took ~14 hours manually now takes ~7h50 — same quality.

MIT-licensed Python (stdlib only). CLI + Claude Code skill.
```
